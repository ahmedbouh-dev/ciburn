# ciburn site

Landing page for ciburn. React + Vite + Tailwind v4, built from library components pulled in with the shadcn CLI:

- shadcn/ui: button, badge
- Magic UI: terminal, marquee, number-ticker, animated-shiny-text, border-beam, code-comparison, magic-card, shimmer-button
- Aceternity UI: spotlight-new
- React Bits: Noise, GradientText

```bash
pnpm install
pnpm dev      # http://localhost:5173
pnpm build    # static output in dist/ (relative paths, ready for GitHub Pages)
```
